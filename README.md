**Acharu** is a premium e-commerce storefront dedicated to traditional, handmade pickles and artisanal food products.

## 🎨 Visual Identity
- **Vibe:** Warm, traditional, and authentic.
- **Colors:** Rich Maroon, Earthy Tones, and Golden Accents.
- **Goal:** To make customers feel the love and care in every jar.

## 🛠️ Features
- **Dynamic Product Grid:** Browsing pickles by category and spice level.
- **Smart Checkout:** Simplified 3-step checkout with delivery fee auto-calculation.
- **Real-time Tracking:** Customers can track their jars from the kitchen to their doorstep.

## 📦 Tech Stack
- **Frontend:** React 19 + Vite
- **Styling:** TailwindCSS
- **State:** Zustand / React Query
- **Icons:** Lucide-React
