# Acharu - Premium Homemade Pickles

A production-ready, mobile-first frontend application for **Acharu**, a premium homemade pickle brand. Built with modern web technologies and a focus on minimal, luxury aesthetics.

## 🚀 Tech Stack
- **Framework**: React (Vite)
- **Styling**: Tailwind CSS v4
- **State Management**: Redux Toolkit (with persistence)
- **Animations**: GSAP & Framer Motion
- **Icons**: Lucide React

## ✨ Key Features
- **Premium Design**: Custom cream & maroon palette with grain texture and glassmorphism.
- **Dynamic Cart**: Full cart functionality with Redux and local storage persistence.
- **Delivery Engine**: Automated calculation based on weight and location.
- **Order Tracking**: Searchable order status system.
- **Responsive**: Fully optimized for mobile, tablet, and desktop (2-column mobile grid).

## 🛠️ Getting Started
1. Clone the repo
2. Run `npm install`
3. Start dev server with `npm run dev`

## 📂 Project Structure
- `/src/components`: Reusable UI components.
- `/src/pages`: Application views and layouts.
- `/src/store`: Redux store and slices.
- `/src/styles`: Global CSS and theme configurations.
- `/src/utils`: Business logic and helper functions.
