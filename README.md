## 🛍️ About Acharu
Acharu is a boutique storefront dedicated to bringing the finest homemade pickles to your doorstep. Built with a focus on speed, aesthetics, and a seamless shopping journey.

## ✨ Features
- **🎨 Artisan UI**: A warm, maroon-themed interface reflecting the richness of traditional pickles.
- **⚡ Fast Checkout**: Optimized checkout flow with real-time address validation.
- **📡 Order Tracking**: Live status updates from "Order Received" to "Out for Delivery".
- **📱 Responsive Design**: Perfectly tailored for mobile foodies.

## 🛰️ Integration
Acharu is powered by the **[Nexus Core Backend](https://github.com/salahuddingfx/Multi_Vedor_Backend)** and managed via the **[Nexus Admin Dashboard](https://github.com/salahuddingfx/Multi_Vendor_Admin-Panel)**.
